# Integration

Each must-have from `ganger/brain/CONSTITUTION.md`, with the file and function that implements it. Every screen reads and writes the Dexie database in `src/db/schema.ts` (through `src/lib/store.ts` or the table itself); no screen keeps its own copy of stored data. Every screen is reached from the sidebar in `src/App.tsx`, which is only shown once a workspace has been chosen on the first screen.

## How the pieces connect
- **Workspaces (pen names):** the first screen (`WorkspaceGate`) asks for a workspace to be chosen or created, with the existing workspaces listed under the create form, and every section (Manuscripts, Outline, Write, Edit, Format, Book Cover, Export, Settings) is nested inside that workspace. The "Workspaces" button at the bottom of the left menu (`WorkspaceSwitcher`, above Settings) switches workspace or adds one.
- **Manuscripts:** there is no manuscript drop-down in the menu. `src/screens/Manuscripts.tsx` lists the workspace's manuscripts on the left; choosing one opens its options (stage, target words, genre, open, delete) on the right, and "About this author" opens the pen-name details. `src/state/AppState.tsx` holds the active workspace and manuscript (saved in the `settings` table), and every book screen works on the manuscript chosen in that list.
- **Genre guide:** "New manuscript" asks for a title and a genre (Fiction or Non-fiction, then a genre with its guide). The genre sets the target word count and keywords, and can start the outline with its structure (`applyGenreStructure`; non-fiction structures are chapters, so "Create chapters from outline" turns them into chapters to write). The genre can be changed later in the manuscript options, the Outline offers its structure when empty, and the AI staff (Outliner, Editor) are told the genre through `genreContext`. The Book Cover brief uses the genre's `coverLook`.
- **Book Cover:** the author's image key (`ImageKeyForm` in Settings, saved by `saveImageAiSettings`) is separate from the text AI key. `BookCover` builds the prompt from the brief, asks the image model for 1 to 3 pictures, stores each in `coverConcepts`, and "Use as cover" puts one on the manuscript so Export includes it.
- **Scenes:** each chapter is a stack of scenes stored inside the chapter HTML as `<section data-segment>` blocks (the attribute keeps its old name so earlier chapters still open), so revisions, suggestions, the preview and the epub keep using the one stored text. `toXhtmlBody` unwraps them for the book.
- **Editing workflow:** progress (`editWorkflow`) is stored on the manuscript; each pass can use a different model, chosen in the Edit screen and stored per provider in `settings` (`editModels`). The AI calls use the author's own key.
- **Outline to Write:** "Start writing this" (`chapterForOutlineItem`) and "Create chapters from outline" (`chaptersFromOutline`, in outline order) make `chapters` rows and link them to the outline item through `chapterId`. Write and Edit share the chosen chapter through `AppState`.
- **Write to Edit:** Edit reads the same `chapters` rows. Accepting a suggestion saves a revision first, then rewrites the chapter text.
- **Format to Export:** The Format screen stores `FormatSettings` on the manuscript. The live preview and the epub both use `buildCss` and the same chapter markup, so the preview matches the exported file.
- **Export:** `buildEpub` produces an EPUB 3 file (with a table of contents, cover, title page, copyright page and KDP metadata) that the author uploads to Amazon KDP.
- **AI staff:** `src/lib/ai.ts` (`askAi`, `requestStageReview`, `requestFormatPreset`) calls OpenAI or Anthropic directly with the key the author enters in `src/screens/Settings.tsx` (saved by `saveAiSettings`). Conversations are saved in `agentMessages` through `src/components/AgentChat.tsx`: Outliner (Outline), Editor and Proofreader (Edit), Formatter (Format). The AI only proposes changes; the author accepts them.

## Accounts and connection
- No sign-in: nothing in the app asks for an account.
- Offline: all data is local (IndexedDB), and `public/sw.js` lets the built app open with no connection. Only the AI staff and the Book Cover picture-making need a connection; their panels turn back on by themselves when the connection returns (`useOnline` in `src/lib/hooks.ts`).

## Settings
The app reads nothing from the environment (`.env.example` says so). The author's AI key and image AI key are entered in the app under Settings.
